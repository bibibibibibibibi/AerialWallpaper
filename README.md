# AerialWallpaper · Windows 动态视频壁纸

把 macOS 风格的官方航拍视频搬上 Windows 桌面：**亮屏/解锁/回到电脑时播放几秒，其余时间定格**——有动态画面的观感，却几乎零开销。

## 特性

- **真·桌面层视频**：窗口挂进 Progman 的子 WorkerW，图标正常点击、不影响使用（宿主线程消息泵 P50 响应 0.02ms）
- **低功耗播放策略**：亮屏 / 解锁 / 空闲回归时自动播放 N 秒后定格，GPU 解码归零、CPU 占用 < 0.1%（单核）
- **片库在线点播**：内置 Apple 官方 4K 航拍片单（89 条，含极光、冰川、沙漠、水母、鲸群、桂林山水等），12 线程并发下载约 9MB/s
- **热切换**：换视频不重启、不闪屏，3 秒生效
- **无缝启动**：登录 / 换片时先把系统静态壁纸换成该片首帧海报，等 mpv 渲染出画面再露出视频窗口——静态到动态之间肉眼无跳变，不会“先露原壁纸再闪一下”
- **原壁纸记忆**：首次启动记下原静态壁纸；停止时优先保留当前画面，无法保留时回退到原壁纸
- **Win32 原生偏好面板**：纯 ctypes，无第三方 Python 运行依赖；大幅圆角预览、青绿色强调色、清楚区分播放偏好与系统集成
- **可搜索的本地视频库**：动态扫描实际视频数量；名称多关键词过滤、点击只预览、双击 / Enter /「使用此视频」才应用
- **更明确的播放设置**：3–30 秒校验、加减步进、5 / 8 / 15 / 30 秒快捷预设、未保存提示和失败反馈；持续播放时禁用不适用的时长控件
- **不阻塞的系统操作**：视频扫描、自启查询、启停壁纸和屏保安装在后台执行；忙碌时防止重复提交，按实际结果显示状态
- **一键打包**：PyInstaller 出 8MB 单文件 exe，另附便携包制作

## 系统要求

- Windows 10 / 11（在 Win11 26H2 4K@150% 上开发测试）
- Python 3.8+（源码运行；标准库即可，无需 pip install）
- [mpv](https://mpv.io/installation/)：任意 Windows 构建，放到 `mpv\mpv.exe`，或在 `config.json` 里指定路径

## 快速开始（源码）

```bat
git clone https://github.com/bibibibibibibibi/AerialWallpaper.git
cd AerialWallpaper
python fetch_aerial.py --list          # 浏览片库（44 条自然类 / 全部 89 条）
python fetch_aerial.py --get 73 --apply   # 下载“帕劳水母湖”并立即设为壁纸
python app.py                         # 打开偏好面板（不自动启动壁纸）
```

`--apply` 会自动写配置并启动播放器。此后每次亮屏/解锁都会自动播放。

下载 mpv 后放至 `mpv\mpv.exe`（若尚未放置，播放器会在启动时报错提示）。

## 快速开始（exe）

> 新偏好面板位于当前源码中。历史 Releases 中的 exe 不会自动更新；要使用此界面，请运行源码或重新打包。

从 [Releases](../../releases) 下载 `AerialWallpaper.exe`（约 8MB，含控制面板 + 后台播放器）：

| 命令 / 操作 | 效果 |
|---|---|
| 双击 exe | 打开控制面板 |
| `AerialWallpaper.exe --run` | 后台播放（开机自启用） |
| `AerialWallpaper.exe --install` / `--uninstall` | 注册 / 移除登录自启（计划任务） |
| `AerialWallpaper.exe --stop` / `--status` | 停止 / 查看状态 |

> exe 不内嵌视频（版权与体积原因）。首次使用可用 [fetch_aerial.py](<fetch_aerial.py>) 下载视频，或将视频放入当前配置的视频所在目录；未配置时依次扫描 `X:\动态壁纸视频` 和应用目录。面板支持 MOV / MP4 / MKV / WEBM / M4V，可点刷新重新扫描。已有海报从 `.thumbs/视频名.jpg` 或同目录的 `视频名.poster.jpg` 读取，缺失时显示占位预览。

## 使用偏好面板

- 左侧显示**静态海报预览**，不是额外启动一个视频解码器。点选列表项只预览；双击、在列表按 Enter 或点「使用此视频」才切换壁纸。
- 视频库提供「全部 / 海洋 / 山川 / 城市 / 沙漠 / 太空 / 冰雪 / 森林 / 其他」景色分类，每项显示全库数量，可与名称搜索组合使用。分类依据已知片源编号及中英文文件名，不会移动、重命名或解码视频；无法判断的文件归入「其他」。已知从太空拍摄的国家／地区片源会正确归入「太空」，不只按地名猜测。
- 点分类只筛选列表和更新静态预览，**不会切换正在播放的壁纸**；仍需「使用此视频」或双击确认。刷新保留当前分类与搜索，清空搜索也不会取消分类。
- 「选择视频」可直接打开其他目录中的本地视频并应用，随后视频库切换到该目录并恢复「全部」分类；取消选择不会保存任何内容。
- 秒数输入 / 加减按钮先编辑草稿，点「保存时长」或在输入框按 Enter 提交。快捷预设直接保存；新秒数**从下一轮播放开始生效**，不会突然打断当前一轮。
- 持续播放开关不会清空原来的秒数；关闭持续播放后仍沿用之前保存的时长。锁屏 / 熄屏 / 屏保的原有暂停逻辑不变。
- 自启与屏保操作会显示忙碌、成功或失败；自启状态无法确认时显示未知，点击开关只重新检查，不会盲目修改系统设置。
- 关闭偏好面板不会停止壁纸；请用「停止壁纸」明确停止。

| 键盘操作 | 效果 |
|---|---|
| Ctrl + F | 聚焦搜索并选中现有关键词 |
| Tab / Shift + Tab | 在可用控件间移动焦点 |
| Space / Enter | 激活当前有焦点的按钮或开关 |
| 搜索框 Enter / Esc | 移到搜索结果 / 清空关键词 |
| 视频列表 Enter | 应用当前预览的视频 |
| 秒数输入框 Enter | 校验并保存草稿 |

面板按当前显示器的 DPI 缩放，并缩小至工作区内，不再因高缩放比例把底部按钮挤出屏幕。

## 安装屏保

- 点「安装屏保」会先生成可执行的屏保，再将其注册为当前用户的屏保；失败时显示原因，不会把不存在的文件登记为屏保。
- **源码版**不再依赖不存在的打包 exe。使用 Windows 自带的 .NET Framework C# 编译器创建小型启动器，安装到 `%LOCALAPPDATA%\AerialWallpaper\screensaver\AerialScreensaver.scr`；启动器调用本次安装的 Python 和源码，与壁纸共用当前视频配置。无需下载编译工具或写入 System32；若系统未提供编译器会明确提示。
- **打包版**仍复制当前程序为同目录的屏保。源码或 Python 移动后，请重新安装屏保以更新启动器路径。
- 安装保留已有等待时间和「恢复时显示登录屏幕」选项；仅在尚无等待时间时设为 600 秒。注册失败会尝试恢复原设置，成功后通知 Windows 更新状态。
- 支持系统预览与设置参数，包括 `/p HWND`、`/p:HWND` 和 `/c:HWND`；关闭预览后启动器也会退出，不留下预览播放器。

## 启动与桌面嵌入故障排查

- 播放器现在只使用支持桌面嵌入的 `gpu-next` / `gpu` / `direct3d` 输出，不再回退到忽略嵌入窗口的 SDL。只有实际出现本次 mpv 进程的渲染子窗口，才显示壁纸并确认启动。
- 若视频可以解码、面板却没有动态画面，先查看 [player.log](<player.log>) 和 [mpv.log](<mpv.log>)；通过面板启动时，Python 启动错误还会追加到 `player-startup.log`。
- Windows 会拒绝低完整性进程把窗口嵌入较高完整性的宿主。隔离工作区中的引擎可能继承低完整性标签；即使同一视频的独立解码测试通过，真实桌面嵌入仍可能失败。可将**同一版本引擎的文件内容**安装到正常应用数据目录（例如 `%LOCALAPPDATA%\AerialWallpaper\mpv\mpv.exe`），并把配置的 `mpv` 字段指向该副本。不要复制低完整性安全标签，也不要为此移除整个工作区的隔离权限。宿主与引擎应以相容的权限运行。
- 配置的播放秒数到期后，画面会正常暂停；需要持续运动时请开启「一直动」，无需改动原来的播放时长。

## 播放逻辑：什么时候动、什么时候停

壁纸播放器只有两个运行状态（外加整体退出），规则全部列在下面，没有隐藏行为。

**核心原则：暂停原因按「来源」分别记录，各自的事件才解除各自的暂停。**
熄屏只由亮屏解除，锁屏只由解锁解除，屏保只由屏保退出解除。
内部事件（定时动一下、换片、面板保存设置）**不会**解除暂停——否则黑屏/屏保后面会偷偷解码。

**「动」——以下任一时刻开始播放（播放 `回到桌面后播放` 设定的秒数，然后自动定格）：**

| 触发 | 说明 |
|---|---|
| 亮屏 | 显示器从灭到亮（解除熄屏暂停） |
| 解锁 / 切回会话 | 锁屏界面输密码回到桌面、远程会话切回（解除锁屏暂停） |
| 屏保退出 | 专用恢复通道，只解除屏保暂停；若屏幕此时已熄屏/锁屏则继续暂停 |
| 面板「立即动一下」 | 用户明确要看画面，解除全部暂停并播放一轮 |
| 换视频 / 启动壁纸 | 新画面出现时先动一轮让你看清 |
| 空闲很久后回来 | 无人操作超过 `config.json` 的 `idle_trigger_seconds`（默认 300 秒=5 分钟）后重新有输入，才播一次。**工作中几十秒的停顿不会触发** |

**「定格」（停止解码，画面停在当前帧，GPU 归零）：**

| 触发 | 说明 |
|---|---|
| 播满设定的秒数 | 默认行为；开启「持续播放」后此条失效 |
| 锁屏 | 黑屏界面后面不需要 4K 解码，立刻定格；解锁后恢复 |
| 熄屏 | 同上；亮屏后恢复 |
| 屏保运行中 | 画面让给屏保，屏保退出后恢复 |

**退出：** 面板「停止壁纸」会退出播放器，优先将当前画面保留为静态壁纸；若无法取得停止帧，则尝试已有海报，再回退到记忆的原壁纸。「启动壁纸」重新拉起，不会重复启动。

**开启「持续播放」后的语义**：持续播放、不按秒数定格，但**锁屏 / 熄屏 / 屏保期间仍然暂停**（屏幕看不见时没必要解码），回到桌面自动恢复。

## 已知限制

- 仅支持单显示器主屏（多屏未适配）
- Windows 10/11 的桌面层实现在版本间差异较大，如壁纸不显示可开 issue 反馈系统版本
- 锁屏界面不可见（锁屏是独立层），仅在登录后的桌面生效

**v1.11（2026-11-18）**
- **修复「面板切换不反应」**（IPC 层重写）：播放器与 mpv 的通信从「长连接只写
  不读」改为一次性连接 RPC（连接→发命令→按回执确认→关闭）。旧架构下 mpv 的
  客户端线程会被事件流写满缓冲后连命令也不读，`pipe.write` 永久阻塞 → 主循环
  冻结（实测卡死 99 秒），面板所有操作没反应、暂停/换片事件全部被吞。
  现在每条命令有回执确认，主循环每 200ms 响应一次，换片 1 秒内就地生效。
- 暂停/恢复/换片全部回执确认制：mpv 没收到就自动重试，不再静默丢失。
- 新增慢迭代看门狗（单次循环 >5 秒留痕），支持 py-spy 在线诊断线程状态。
